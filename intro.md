# CKA Practice Labs 2025

Welcome to the **CKA Practice Lab** — 19 hands-on questions designed to mirror the real Certified Kubernetes Administrator exam.

## How this works

- The **terminal on the right** is a live Kubernetes cluster (kubeadm, 2 nodes)
- Each question **auto-configures** the cluster — just click **START** on each step
- Use the **Check** button to validate your solution
- Click **Continue** to move to the next question

## Available helper commands

Once the lab loads, these commands work in the terminal:

| Command | What it does |
|---------|-------------|
| `hint` | Show step-by-step solution notes |
| `validate` | Re-run validation checks |
| `cleanup` | Remove resources from current question |
| `lab <N>` | Jump to any question by number |
